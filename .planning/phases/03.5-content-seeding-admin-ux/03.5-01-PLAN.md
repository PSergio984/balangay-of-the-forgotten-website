# Plan 03.5-01: Admin UX Improvements

## Goal
Make the Payload admin panel ergonomic for ongoing content management: slug auto-generation, sprite thumbnail previews in list views, and improved relation field labels.

## must_haves
- Typing a name in any collection auto-fills the slug field
- List views for Bosses, Characters, Minibosses, Relics show a sprite image thumbnail column
- Relation pickers (e.g. Boss → Location) show the entry name correctly (useAsTitle already set; verify)
- All changes regenerate `payload-types.ts` cleanly
- Dev server starts without errors after changes

---

## Wave 1 — Shared Slug Utility

### Task 1.1 — Create shared slug hook utility

<read_first>
- collections/Bosses.ts
- payload.config.ts
</read_first>

<action>
Create `lib/slug.ts` exporting:
1. `formatSlug(val: string): string` — replaces spaces with `-`, strips non-word chars, lowercases
2. `slugHook(fallbackField: string): FieldHook` — beforeChange hook: if `value` is non-empty string, return `formatSlug(value)`; else if `operation === 'create'` or no value, read `data?.[fallbackField]` or `originalDoc?.[fallbackField]` and return `formatSlug(fallback)` if it exists; otherwise return `value` unchanged

Import types: `FieldHook` from `'payload'`
</action>

<acceptance_criteria>
- `lib/slug.ts` exists and exports `formatSlug` and `slugHook`
- `formatSlug('Diwata ng Dagat')` returns `'diwata-ng-dagat'`
- `formatSlug('Apo Mallari!')` returns `'apo-mallari'`
- TypeScript compiles without errors
</acceptance_criteria>

## Wave 3 — Thumbnail Cell Component

### Task 3.1 — Create ImageThumbnailCell admin component

<read_first>
- collections/Bosses.ts (to understand the image field shape: upload relationTo media)
- payload.config.ts (for importMap.baseDir)
</read_first>

<action>
Create `components/admin/ImageThumbnailCell.tsx`:
- Add `'use client'` directive at top
- Import `React` from `'react'`
- Import `DefaultCellComponentProps` from `'payload'`
- Export named `ImageThumbnailCell` and a default export pointing to the same component
- Component receives `{ rowData }` — extract `rowData?.image` which may be an object with `url` or null
- If `image` is object with `url`, render `<img src={url} alt={rowData?.name || 'preview'} style={{ width: 36, height: 36, objectFit: 'contain', imageRendering: 'pixelated' }} />`
- If no url, render `<span style={{ color: '#aaa', fontSize: '10px' }}>—</span>`
</action>

<acceptance_criteria>
- `components/admin/ImageThumbnailCell.tsx` exists
- File has `'use client'` directive
- Exports both named `ImageThumbnailCell` and a default export
- Handles null/undefined image gracefully (renders `—` placeholder)
- TypeScript compiles without errors
</acceptance_criteria>
